# CSS Grid – Properties Overview

> ⏰ **Time Note:** 9:30  
> Grid properties are divided into **two main categories**:
>
> - Parent (Container) properties
> - Children (Item) properties

---

## Parent (Container) Properties

These properties are applied to the **grid container**.

### 🔹 Layout Definition

- `grid-template-columns`
- `grid-template-rows`
- `grid-template`

### Spacing (Gaps)

- `column-gap`
- `row-gap`
- `grid-gap`

### Alignment

- `justify-items`
- `align-items`
- `justify-content`
- `place-items`
- `place-content`

---

## Children (Grid Item) Properties

These properties are applied to the **grid items** inside the container.

### Positioning

- `grid-column` → start / end
- `grid-row` → start / end

### Self Alignment

- `justify-self`
- `align-self`
- `place-self`
